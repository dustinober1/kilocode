<task type="auto">
  <name>Task 2: Implement AggregationService with window function queries</name>
  <files>cli/src/services/analytics/AggregationService.ts</files>
  <action>
    Create AggregationService singleton with:

    1. Constructor gets db from StorageService.getInstance().getDatabase()
    2. getInstance() singleton pattern
    3. getSessionMetrics(sessionId: string) using SQL aggregation:
       - COUNT(*) as event_count
       - SUM of extracted cost from json_extract(metadata, '$.cost') as total_cost
       - MIN(timestamp) as first_event, MAX(timestamp) as last_event
       - WHERE session_id = ${sessionId}

    4. getTokenUsageTimeline(sessionId: string) using window functions:
       - SELECT timestamp, tokens, SUM(tokens) OVER (ORDER BY timestamp ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) as running_total
       - CAST(json_extract(metadata, '$.promptTokens') AS INTEGER) + CAST(json_extract(metadata, '$.completionTokens') AS INTEGER) as tokens
       - WHERE session_id = ${sessionId} AND event_type = 'token:used'
       - ORDER BY timestamp DESC LIMIT 100

    5. getHistoricalSessions(limit: number = 20) for session list:
       - SELECT * FROM sessions ORDER BY start_time DESC LIMIT ${limit}
       - Returns array of session objects

    6. getTokensPerMinute(sessionId: string) using time bucketing:
       - SELECT strftime('%Y-%m-%d %H:%M', timestamp) as minute, SUM(tokens) as tokens
       - WHERE session_id = ${sessionId} AND event_type = 'token:used'
       - GROUP BY minute ORDER BY minute

    All methods use aggregationCache.get() before query, set() after query.
    Use sql template literal from drizzle-orm for raw SQL queries.

  </action>

  </verify>
