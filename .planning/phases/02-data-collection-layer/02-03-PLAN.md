    Update MetricsCollectorService to use EventQueue instead of direct StorageService calls:

    **Changes to existing MetricsCollectorService.ts:**

    1. Import EventQueue:
       ```typescript
       import { EventQueue } from './queue/EventQueue'
       ```

    2. Add private property:
       ```typescript
       private queue: EventQueue
       ```

    3. In constructor, initialize queue:
       ```typescript
       this.queue = new EventQueue(1000)
       ```

    4. Setup periodic flush interval:
       ```typescript
       private flushInterval: NodeJS.Timeout | null = null

       // In constructor:
       this.flushInterval = setInterval(() => this.flush(), 1000)
       ```

    5. Add flush() method:
       ```typescript
       private async flush(): Promise<void> {
         const batch = this.queue.dequeueBatch(100)
         if (batch.length === 0) return

         try {
           const eventsToInsert = batch.map(event => ({
             sessionId: this.currentSessionId || '',
             eventType: event.type,
             timestamp: event.timestamp,
             metadata: JSON.stringify(event.data)
           }))

           await this.storage.insertEvents(eventsToInsert)
         } catch (error) {
           console.error('Failed to flush metrics:', error)
           this.queue.requeue(batch)
         }
       }
       ```

    6. Update emit() to use queue:
       ```typescript
       public emit<K extends keyof MetricsEvents>(event: K, data: MetricsEvents[K]): boolean {
         if (this.isShutdown) return false
         if (!this.privacyConfig.enabled) return false

         const sanitized = this.privacyConfig.filterPrompts
           ? PIISanitizer.sanitize(data)
           : data

         this.queue.enqueue({
           type: event,
           data: sanitized,
           timestamp: new Date()
         })

         return super.emit(event, data)
       }
       ```

    7. Update shutdown() to clear interval and final flush:
       ```typescript
       public async shutdown(): Promise<void> {
         this.isShutdown = true
         this.emit('shutdown')

         if (this.flushInterval) {
           clearInterval(this.flushInterval)
           this.flushInterval = null
         }

         await this.flush()  // Final flush
         await this.storage.close()
         this.removeAllListeners()
       }
       ```

    This decouples event capture from database writes, ensuring <5ms latency for emit() calls.

  </action>

    - flush() method dequeues batch and calls storage.insertEvents()
    - Periodic flush configured (1000ms interval)
    - shutdown() clears interval and calls final flush
  </verify>
  <done>MetricsCollectorService now uses EventQueue for async batching with periodic flush</done>
