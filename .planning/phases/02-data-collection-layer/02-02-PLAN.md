  <action>
    Create EventQueue class implementing fixed-size ring buffer:

    **Class properties:**
    - `buffer: MetricEvent[]` - Array backing the ring buffer
    - `head: number` - Index of oldest element
    - `tail: number` - Index where next element goes
    - `size: number` - Current number of elements
    - `capacity: number` - Maximum capacity (1000 events)

    **Constructor:**
    - Accept capacity parameter (default 1000)
    - Initialize buffer as new Array(capacity)
    - Set head = 0, tail = 0, size = 0

    **Methods:**

    1. `enqueue(event: MetricEvent): void` - Add event to queue:
       ```typescript
       if (this.size === this.capacity) {
         // Overwrite oldest: move head forward
         this.head = (this.head + 1) % this.capacity
       } else {
         this.size++
       }
       this.buffer[this.tail] = event
       this.tail = (this.tail + 1) % this.capacity
       ```

    2. `dequeueBatch(batchSize: number): MetricEvent[]` - Remove up to batchSize events:
       ```typescript
       const result: MetricEvent[] = []
       for (let i = 0; i < batchSize && this.size > 0; i++) {
         result.push(this.buffer[this.head]!)
         this.head = (this.head + 1) % this.capacity
         this.size--
       }
       return result
       ```

    3. `requeue(events: MetricEvent[]): void` - Add events back to front:
       ```typescript
       for (const event of events) {
         this.enqueue(event)
       }
       ```

    4. `getLength(): number` - Return current size
    5. `isEmpty(): boolean` - Return true if size === 0
    6. `isFull(): boolean` - Return true if size === capacity

    **MetricEvent type:**
    - Import from '../types'
    - Use MetricEvent interface from Plan 01

    **Key implementation details:**
    - Use modulo operator (%) for wraparound: `(index + 1) % capacity`
    - Handle capacity === 0 edge case (throw error)
    - Use non-null assertions (!) after checking size > 0
    - All operations are O(1) except dequeueBatch which is O(batchSize)
